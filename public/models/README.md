# Model Assets — Attribution & Licenses

This directory contains 3D model files (`.glb`) used by the RoboWebSim model library.

## Asset policy

- No live third-party model API is required at runtime.
- Shipped GLB assets are stored locally.
- Asset source and license metadata is kept alongside the model-library definitions.
- The GLB geometry currently shipped in this directory is procedurally generated by RoboWebSim and released as CC0 1.0.

## Preview images

Preview thumbnails are stored in `/public/model-previews/` and are used by model-library cards when a `previewImage` path is configured.

## Generating models

The current GLB assets are generated by:

```text
scripts/generate-models.js
```

Run:

```bash
node scripts/generate-models.js
```

Generated files are written to `scripts/out/` before being copied into this directory for use by the application.
