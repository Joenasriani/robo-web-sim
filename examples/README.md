# Examples

This directory contains example RoboWebSim data and configuration files.

## `custom-arena.json`

A schema-oriented example of an arena configuration.

It demonstrates:

- arena size
- wall and floor colors
- obstacle IDs
- obstacle positions and dimensions
- obstacle colors
- target IDs
- target positions
- target radius and color

The file documents the structure used by RoboWebSim arena data. It should not be described as directly importable by the UI unless the current application explicitly supports that import path.

Additional examples should be added only when they exist in the repository and are validated against the current simulator data model.
