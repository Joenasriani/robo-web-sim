> النسخة الإنجليزية من README هي المرجع الأساسي. قد تتأخر الترجمات قليلًا عن أحدث إصدار.

**محاكي ثلاثي الأبعاد للبرمجة والروبوتات والملاحة يعمل مباشرة في المتصفح.**

يتيح RoboWebSim للمتعلمين والمطورين برمجة روبوت، تشغيل سلاسل أوامر مرتبة، بناء برامج باستخدام Blockly، فحص الحساسات الافتراضية، تعديل ساحات ثلاثية الأبعاد، والعمل عبر دروس موجهة مباشرة داخل المتصفح.

**المحاكي المباشر:** https://robo-web-sim.vercel.app  
**اللعبة العامة:** https://joenasr.itch.io/robosim

> RoboWebSim مصمم كمحاكي تعليمي يعتمد على المتصفح أولًا. لا يحتاج إلى ROS أو خادم روبوتات أو بيئة محاكاة أصلية.

## ماذا يمكنك أن تفعل

- التحكم بالروبوت داخل ساحة ثلاثية الأبعاد قابلة للتخصيص
- بناء برامج للروبوت باستخدام Blockly
- تشغيل قوائم أوامر مرتبة مع التشغيل والإيقاف المؤقت والإيقاف وإعادة البدء وإعادة التشغيل
- العمل عبر دروس تعتمد على البيانات مع شروط إكمال واضحة
- تحميل سيناريوهات اللعب الحر
- فحص قراءات حساسات افتراضية حتمية
- تعديل العوائق والأهداف داخل الساحة
- إضافة عناصر مدمجة ونماذج GLB محلية
- حفظ واستعادة مشاهد الساحة محليًا
- حفظ البرامج وتحميلها وإعادة تسميتها وحذفها واستيرادها
- استخدام المحاكي على سطح المكتب والموبايل

## البدء السريع

المتطلبات:

- إصدار Node.js المدعوم من شجرة الاعتماد الحالية
- npm
- متصفح حديث يدعم WebGL

```bash
git clone https://github.com/Joenasriani/robo-web-sim.git
cd robo-web-sim
npm install
npm run dev
```

ثم افتح:

```text
http://localhost:3000
```

بناء الإنتاج:

```bash
npm run build
npm start
```

التحقق:

```bash
npm run lint
npm test -- --runInBand
npm run build
```

## أول برنامج للروبوت

مسار نجاح بسيط:

1. افتح `/simulator`.
2. حمّل سيناريو لعب حر للمبتدئين.
3. أضف كتل الحركة داخل مساحة Blockly.
4. شغّل البرنامج.
5. راقب قائمة الأوامر، حركة الروبوت، حالة الحساسات، ونتيجة الوصول إلى الهدف أو الاصطدام.

Blockly وقائمة الأوامر المرئية يستخدمان تمثيل الأوامر الأصلي نفسه داخل المحاكي.

## المسارات الرئيسية

### `/`
صفحة التعريف بالمشروع ونقطة الدخول إلى المحاكي.

### `/simulator`
مساحة العمل الرئيسية ثلاثية الأبعاد: التحكم، Blockly، قائمة الأوامر، الدروس، السيناريوهات، تعديل الساحة، مكتبة النماذج، القياسات، الحساسات وسجل الأحداث.

### `/lessons`
متصفح الدروس وعرض التقدم المحلي.

## البنية

RoboWebSim مبني باستخدام Next.js 16 وReact 19 وTypeScript.

المكونات الأساسية:

- Next.js App Router
- React 19
- Three.js
- React Three Fiber
- @react-three/drei
- Zustand
- Blockly
- Tailwind CSS
- `localStorage`
- Jest / jsdom

طبقات النظام الأساسية هي: منطق المحاكاة، العرض ثلاثي الأبعاد، ووحدة التحكم بالحالة والتنفيذ.

لمزيد من التفاصيل راجع [docs/ARCHITECTURE.md](../ARCHITECTURE.md).

## نموذج الحركة

الحركة حتمية وتعتمد على خطوات ثابتة.

- خطوة الحركة الافتراضية: `0.5`
- خطوة الدوران الافتراضية: `π / 8`

الأوامر المدعومة:

- `forward`
- `backward`
- `left`
- `right`
- `wait`

## نطاق المحاكاة

RoboWebSim يركز على تعليم الروبوتات، منطق الأوامر، الملاحة، بناء البيئات، والبرمجة التعليمية داخل المتصفح.

لا يدّعي المشروع حاليًا توفير:

- فيزياء أجسام صلبة مستمرة
- ديناميكيات روبوتات موثقة بحثيًا
- تكامل ROS
- توافق Webots
- تحكم Hardware-in-the-loop
- تحكم بروبوت مادي
- ضوضاء حساسات واقعية
- محاكاة روبوتات بحثية متقدمة
